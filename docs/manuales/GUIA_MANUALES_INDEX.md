# Manuales REGINSA

## Regla de canonicos

Las guias dentro de `docs/manuales/` son la fuente canonica operativa.

Cuando exista una guia equivalente en `docs/` (raiz), esa guia de raiz debe marcarse como deprecada y mantenerse solo como referencia historica.
